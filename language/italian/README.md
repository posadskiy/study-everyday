# Italian (Beginner - Level 0)

You said your Italian level is **zero**. This folder contains **5 starter lessons** designed to get you speaking from day 1.

## How to use these lessons (simple routine)

- **Step 1 (5 min)**: Read the lesson out loud once (even if slowly).
- **Step 2 (10 min)**: Learn the vocabulary list (say each word out loud).
- **Step 3 (5–10 min)**: Do the exercises, then check the **Answer key**.
- **Daily review (2–5 min)**: Re-read yesterday’s dialogue and redo 2–3 old exercises.

## Lessons

- `lessons/lesson-01.md` — Greetings + pronunciation essentials + introducing yourself
- `lessons/lesson-02.md` — Articles + gender/plurals + numbers 0–20
- `lessons/lesson-03.md` — Verbs **essere** / **avere** + simple questions + “I am / I have”
- `lessons/lesson-04.md` — Present tense regular **-are** verbs + “where do you live?” + routine
- `lessons/lesson-05.md` — Ordering at a café + polite requests (**vorrei**) + prices

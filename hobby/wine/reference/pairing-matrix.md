# Food & Wine Pairing Matrix

Quick reference guide. See [Module 8](../modules/08-food-pairing.md) for the full pairing principles.

---

## The Core Rules (in 4 lines)

1. **Match weight:** light food → light wine; rich food → rich wine
2. **Tannin needs protein/fat:** high-tannin reds with red meat; never with fish
3. **Acidity beats everything:** high-acid wines work with almost any food
4. **Sweet wine ≥ sweet food:** always match or exceed food's sweetness

## Full Pairing Matrix

| Food | Best Matches | Good Matches | Avoid |
|------|-------------|-------------|-------|
| **SEAFOOD** | | | |
| Oysters, raw shellfish | Champagne/sparkling, Muscadet, Chablis, Albariño | Dry Riesling, Sauvignon Blanc | Tannic reds, oaked whites |
| Grilled/steamed fish | Sauvignon Blanc, Pinot Grigio, light Chardonnay | Albariño, Picpoul, dry Riesling | Full tannic reds |
| Rich fish (salmon, tuna, swordfish) | White Burgundy, Viognier, Grüner Veltliner | Pinot Noir, rosé | Very tannic reds |
| Fish stew / brodetto | Friulano, Vitovska, dry Malvasia, Vermentino | Dry Riesling, unoaked Chardonnay | Tannic reds |
| Fried fish | Champagne/Cava, Soave, Verdicchio | Sauvignon Blanc, Pinot Grigio | Tannic reds |
| Sushi / sashimi | Dry Riesling, Champagne, Grüner Veltliner | Albariño, Pinot Gris | High-tannin reds |
| **POULTRY** | | | |
| Roast chicken | White Burgundy, oaked Chardonnay | Pinot Noir, Friulano, Viognier | Very tannic reds |
| Duck (roast or confit) | Pinot Noir, Côtes du Rhône, Merlot | Riesling Spätlese, orange wine | Very heavy reds |
| Turkey | Pinot Noir, Gamay, medium Chardonnay | Grenache, rosé | Very tannic heavy reds |
| Chicken with herbs / light sauce | Friulano, Sauvignon Blanc, Zelen | Pinot Grigio, Vermentino | Full oaked reds |
| **PORK** | | | |
| Roast pork | Riesling, Pinot Noir, Barbera, orange wine | Grenache, Chardonnay, Garganega | Very heavy reds |
| Pork belly / fatty cuts | Riesling, Barbera, Dolcetto, Champagne | Côtes du Rhône, light reds | Dry, lean whites alone |
| Prosciutto / San Daniele | Friulano, Prosecco, Pinot Grigio | Ribolla Gialla, dry Malvasia | Heavy tannic reds |
| Kraški pršut | Vitovska, dry rosé, Zelen, Teran | Ribolla Gialla, Malvasia | Highly oaked wines |
| Sausage / charcuterie | Barbera, Dolcetto, orange wine, Beaujolais | Zinfandel, Grenache, Sparkling | Very tannic wines |
| **BEEF & LAMB** | | | |
| Grilled steak | Cabernet Sauvignon, Malbec, Syrah | Rioja Reserva, Barolo | Delicate whites |
| Roast beef | Bordeaux, Rioja, Brunello | Merlot, Syrah, Zinfandel | Delicate whites |
| Braised beef (stew) | Barolo, Barbaresco, Syrah, Bandol | Rioja Gran Reserva, Amarone | Aromatic or light whites |
| Lamb (roast) | Cabernet Sauvignon, Rioja, Côte-Rôtie | Merlot, Grenache, Malbec | Delicate whites |
| Burgers | Zinfandel, Grenache, Barbera | Merlot, Shiraz | High-acid delicate whites |
| **GAME** | | | |
| Wild boar / venison | Barolo, Amarone, Pignolo, Sagrantino | Syrah, Cabernet Sauvignon | Delicate whites |
| Pheasant / partridge | Schioppettino, Pinot Noir, Dolcetto | Barbera, Chianti | Heavy/oaky reds |
| Duck confit | Pinot Noir, Pomerol, Schioppettino | Orange wine, Grenache | Very aromatic whites |
| **PASTA & RICE** | | | |
| Tomato/meat sauce | Sangiovese/Chianti, Barbera, Primitivo | Dolcetto, Montepulciano d'Abruzzo | High-tannin heavy reds |
| Cream sauce | White Burgundy, oaked Chardonnay | Friulano, Soave Classico | Very tannic reds |
| Seafood pasta | Vermentino, Friulano, Pinot Grigio | Dry Riesling, Sauvignon Blanc | Full reds |
| Mushroom risotto | Pinot Noir, Barbera, Dolcetto | Chardonnay, orange wine | Very tannic heavy reds |
| Truffle pasta | Barolo, Barbaresco, Burgundy red | Friulano, aged Chardonnay | Aromatic whites |
| Cjarsons (FVG sweet-savory pasta) | Friulano, off-dry Riesling | Ribolla Gialla | Heavy tannic reds |
| **REGIONAL FVG & SLOVENIAN** | | | |
| Frico (cheese & potato) | Friulano, dry Malvasia | Ribolla Gialla, Pinot Grigio | Heavy reds |
| Brovada e muset (turnips/sausage) | Refosco, Schioppettino | Orange wine, Terrano/Teran | Delicate whites |
| Jota (bean & sauerkraut stew) | Teran, Refosco, orange wine | Medium reds | Very aromatic whites |
| Brodetto (fish stew) | Friulano, Vitovska, Malvasia | Dry Riesling | Any red wine |
| Žlikrofi (potato dumplings) | Rebula, Pinela, Friulano | Zelen | Heavy tannic reds |
| Bograč (goulash) | Modra Frankinja, Refosco | Syrah, Merlot | Aromatic whites |
| **VEGETARIAN** | | | |
| Green salad / vinaigrette | Sauvignon Blanc, Zelen, Pinela | Dry Riesling, Vinho Verde | Tannic reds |
| Grilled vegetables | Orange wine, Grenache, Vermentino | Sauvignon Blanc, rosé | Heavy tannic reds |
| Mushrooms | Pinot Noir, Barbera, orange wine | Chardonnay, Chablis | Very aromatic perfumed whites |
| Asparagus | Sauvignon Blanc, Grüner Veltliner | Dry Riesling, Pinot Grigio | Tannic reds |
| Eggplant / ratatouille | Grenache, Syrah (Rhône), Primitivo | Sangiovese, orange wine | Delicate whites |
| **CHEESE** | | | |
| Fresh cheese (mozzarella, ricotta) | Light sparkling, Pinot Grigio, Sauvignon Blanc | Friulano, Soave | Heavy tannic reds |
| Semi-soft (Brie, Camembert) | Champagne, white Burgundy, Pinot Noir | Chenin Blanc, Riesling | Very tannic reds |
| Hard aged (Parmigiano, Cheddar, Montasio aged) | Orange wine, Amarone, Barolo | Rioja Reserva, aged Chardonnay | Delicate whites |
| Blue cheese (Roquefort, Stilton, Gorgonzola) | Sauternes, Port, Moscato | Ice wine, TBA | Dry tannic reds |
| Goat cheese | Sancerre, Sauvignon Blanc | Pinot Grigio, dry Riesling | Tannic reds |
| Washed-rind / pungent | Gewürztraminer, Alsace Pinot Gris | Beer (honestly) | Delicate whites |
| **SPICY FOOD** | | | |
| Thai / Vietnamese | Dry or off-dry Riesling, Gewürztraminer | Sparkling, Pinot Grigio | High-tannin reds (amplifies heat) |
| Indian curry | Off-dry Riesling, Gewürztraminer | Sparkling, Pinot Noir (light) | Tannic reds, very oaky wines |
| Sichuan / Chinese | Off-dry Riesling, Gewürztraminer | Sparkling rosé | Heavy reds |
| **DESSERT** | | | |
| Chocolate (dark) | Banyuls, Maury, vintage Port, Amarone | Tawny Port, Zinfandel (late harvest) | Dry tannic reds |
| Fruit tart / crumble | Sauternes, Barsac, Vendange Tardive Riesling | Moscato d'Asti, Demi-Sec Champagne | Dry wines |
| Tiramisu | Marsala, Vin Santo, Tawny Port | Moscato d'Asti | Dry wines |
| Potica / Prekmurska gibanica | Slovenian late-harvest whites, Renski Rizling | Tawny Port | Dry wines |
| Foie gras | Sauternes, Tokaji, late-harvest Gewürztraminer | Vintage Champagne | Tannic reds, dry lean whites |
| **APERITIVO** | | | |
| Mixed appetizers / tapas | Fino Sherry, Champagne/Cava/Prosecco | Zelen, Albariño, Sauvignon Blanc | Heavy reds |
| Nuts / olives | Fino/Manzanilla Sherry, dry Amontillado | Cava, Vermentino | Sweet wines |

## By Wine Style: What to Eat

| Wine Style | Best With |
|-----------|----------|
| Champagne / Sparkling (dry) | Almost anything, especially fried food, shellfish, salty snacks |
| Chablis / unoaked Chardonnay | Oysters, steamed seafood, light salads |
| White Burgundy / oaked Chardonnay | Lobster, cream sauces, roast chicken, veal |
| Sauvignon Blanc | Goat cheese, green vegetables, grilled white fish |
| Dry Riesling | Spicy food, pork, sushi, smoked salmon |
| Albariño | Atlantic seafood, shellfish, octopus |
| Friulano | Prosciutto, frico, light pasta, cheese, seafood |
| Ribolla Gialla (conventional) | Seafood, light pasta, risotto |
| Ribolla / Rebula (orange wine) | Pork, charcuterie, aged cheese, grilled vegetables |
| Vitovska | Seafood, oysters, Karst cheese, cold cuts |
| Zelen | Vegetables, light fish, herby dishes, aperitivo |
| Beaujolais / Gamay | Charcuterie, light pasta, pizza, salmon |
| Pinot Noir | Duck, salmon, mushrooms, charcuterie, Gruyère |
| Barbera | Pasta with tomato sauce, sausage, pizza |
| Sangiovese / Chianti | All Italian food, especially tomato and meat sauces |
| Barolo / Nebbiolo | Truffles, braised game, aged hard cheese |
| Merlot | Duck, pork, pasta with meat sauce |
| Cabernet Sauvignon | Red meat, lamb, aged hard cheese |
| Syrah (cool/peppery) | Lamb, game, grilled meats |
| Shiraz (ripe/jammy) | BBQ, rich stews, spiced meats |
| Grenache | Mediterranean food, lamb, tapas, paella |
| Refosco / Teran | Brovada e muset, game, fatty sausages, jota |
| Schioppettino | Game, pheasant, mushrooms |
| Amarone | Rich game, braised beef, aged hard cheese |
| Sauternes | Foie gras, blue cheese, fruit dessert |
| Tawny Port | Nuts, crème brûlée, toffee desserts |
| Vintage Port | Stilton, dark chocolate |
| Fino/Manzanilla Sherry | Jamón, tapas, olives, seafood |

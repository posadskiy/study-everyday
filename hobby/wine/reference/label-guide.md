# Label Guide — Decoding Wine Labels by Country

---

## France

### Key Principle: Labels Show Place, Not Grape

| What You See | What It Means | Grape(s) |
|-------------|---------------|---------|
| Chablis | White wine from Chablis AOC, Burgundy | Chardonnay |
| Meursault | White wine from Meursault commune, Burgundy | Chardonnay |
| Gevrey-Chambertin | Red wine from that commune, Burgundy | Pinot Noir |
| Pomerol | Red wine from Pomerol, Bordeaux | Merlot dominant |
| Pauillac | Red wine from Pauillac, Bordeaux | Cabernet Sauvignon dominant |
| Sancerre | White wine from Sancerre, Loire | Sauvignon Blanc |
| Condrieu | White wine from Condrieu, N. Rhône | Viognier |
| Châteauneuf-du-Pape | Red or white wine, S. Rhône | Red: Grenache dominant; White: Grenache Blanc, Roussanne |

### Appellation Hierarchy (broadest → most specific)

```
Vin de France → IGP [region] → AOC [regional] → AOC [village] → AOC [Premier Cru] → AOC [Grand Cru]
```

### Key Label Terms

| French | Meaning |
|--------|---------|
| Château | Wine estate (especially Bordeaux) |
| Domaine | Wine estate (Burgundy/Rhône) |
| Mis en bouteille au Château / Domaine | Estate-bottled |
| Vieilles Vignes | Old vines |
| Clos | Enclosed/walled vineyard |
| Premier Cru (1er Cru) | First-classified vineyard |
| Grand Cru | Highest classification |
| Négociant | Merchant wine |
| Récoltant | Grower-producer |
| Brut / Extra Brut / Demi-Sec | Sparkling wine sweetness |
| Blanc de Blancs | 100% white grapes (Champagne) |
| Blanc de Noirs | 100% red grapes, white wine |
| Non-Vintage (NV) | Blended from multiple years |
| Millésime | Vintage (on Champagne) |

### Bordeaux Classification (1855)

Premier Grand Cru Classé (1st Growths): Château Margaux, Mouton Rothschild, Latour, Lafite Rothschild, Haut-Brion  
→ Second through Fifth Growths follow.  
Right Bank: Saint-Émilion has its own Premier Grand Cru Classé A (Pétrus is not classified but exceeds all in price)

## Italy

### Key Principle: Complex Mix of Place and Grape

| What You See | Appellation Type | What It Tells You |
|-------------|-----------------|------------------|
| Barolo DOCG | Place only | 100% Nebbiolo from Barolo |
| Chianti Classico DOCG | Place only | Sangiovese dominant (min 80%) |
| Collio DOC Friulano | Place + Grape | Friulano grape from Collio |
| Collio DOC Ribolla Gialla | Place + Grape | Ribolla Gialla from Collio |
| Toscana IGT | Broad region | Anything; often Super Tuscans |
| Montepulciano d'Abruzzo DOC | Grape + Place | Montepulciano grape from Abruzzo |

### Quality Tiers

```
DOCG (Denominazione di Origine Controllata e Garantita) ← Highest, "guaranteed"
DOC (Denominazione di Origine Controllata)
IGT (Indicazione Geografica Tipica)                    ← Broad; some icons are IGT
Vino d'Italia                                          ← Basic
```

### Aging Terms

| Term | Minimum Aging | Notes |
|------|--------------|-------|
| Normale / Annata | Varies by DOC | Basic release |
| Superiore | Usually +6 months | Higher alcohol or longer aging |
| Riserva | Varies: 2–5 years total | Extended aging |
| Gran Selezione | 30 months (Chianti Classico) | Single vineyard, top tier |
| Barolo normale | 3 years (2 in wood) | Minimum |
| Barolo Riserva | 5 years | Extended |
| Brunello di Montalcino | 5 years (6 for Riserva) | Long mandatory aging |
| Amarone | 2 years minimum | Often aged much longer |

### FVG-Specific Labels

Friuli labels typically show appellation + grape variety:
- `COLLIO DOC FRIULANO` → Friulano grape from Collio  
- `COLLI ORIENTALI DEL FRIULI DOC SCHIOPPETTINO` → Schioppettino from COF  
- `FRIULI ISONZO DOC PINOT GRIGIO` → Best Pinot Grigio zone in Italy  
- `CARSO DOC VITOVSKA` → Vitovska from the Karst

## Slovenia

### Quality System

```
ZGP (Zaščitena geografska poreklo / PDO) ← Protected Designation of Origin
  └── Vrhunsko vino PDO (premium quality — highest tier)
  └── Kakovostno vino PDO (quality wine)
PGO (Zaščitena geografska označba / PGI) ← Broader indication
  └── Deželno vino PGI (regional wine)
Namizno vino ← Basic table wine
```

### Main ZGP Appellations in Primorska

| ZGP | Sub-region | Key Wines |
|-----|-----------|----------|
| ZGP Goriška Brda | Brda hills | Rebula, Jakot, white blends |
| ZGP Vipavska Dolina | Vipava Valley | Zelen, Pinela, Vitovska, Merlot |
| ZGP Kras | Karst plateau | Vitovska (PDO), Teran (PDO) |
| ZGP Slovenska Istra | Coastal | Malvazija (= Malvasia), Refosk |

### Slovenian Label Anatomy

```
PRODUCER NAME               ← e.g., Movia, Batič, Čotar
WINE NAME (if applicable)   ← Brand name or blend name
GRAPE VARIETY               ← e.g., Rebula, Zelen, Teran
SUB-REGION                  ← e.g., Brda, Vipavska dolina
ZGP [APPELLATION]           ← e.g., ZGP Goriška Brda
VINTAGE (LETNIK)            ← Year
QUALITY TIER                ← e.g., Vrhunsko vino ZGP
PRIDELANO V SLOVENIJI       ← "Produced in Slovenia"
VOLUME + ALCOHOL            ← e.g., 750 ml, 13% vol
```

### Back Label (Mandatory in Slovenia)

Slovenian law requires:
- Organoleptic description (color, aroma, taste) — *Barva / Vonj / Okus*
- Recommended serving temperature — *Priporočena temperatura strežbe*
- Food pairing suggestion — *Priporoča se k*

### Slovenian Quality Terms

| Slovenian | Meaning |
|-----------|---------|
| Vrhunsko vino | Premium quality wine (highest tier) |
| Kakovostno vino | Quality wine |
| Deželno vino | Regional wine |
| Suho | Dry |
| Polsuho | Off-dry |
| Polsladko | Semi-sweet |
| Sladko | Sweet |
| Peneče vino | Sparkling wine |
| Ekološko | Organic |

## Spain

### Appellation Tiers

```
DOCa (Denominación de Origen Calificada) ← Only Rioja and Priorat
DO (Denominación de Origen)              ← Most quality wines
IGP (Indicación Geográfica Protegida)
Vino de España
```

### Rioja Aging Classification (on back label capsule)

| Rioja Label | Total Aging | Oak Minimum | Character |
|-------------|-------------|-------------|-----------|
| Joven | None required | None | Fresh, fruity, drink young |
| Crianza | 2 years | 1 year in oak | Medium structure |
| Reserva | 3 years | 1 year in oak | More complex |
| Gran Reserva | 5 years | 2 years in oak | Complex, aged, food wine |

### Key Spanish Label Terms

| Spanish | Meaning |
|---------|---------|
| Bodega | Winery |
| Viña / Viñedo | Vineyard |
| Crianza | "Raised" — aged in oak + bottle |
| Reserva | Reserve — longer aging |
| Gran Reserva | Longest aging |
| Vino de Pago | Single-estate wine (prestigious) |
| Denominación de Origen | DO — controlled appellation |
| Cosecha | Harvest / vintage |
| Embotellado en origen | Estate-bottled |

## Germany

### Quality Hierarchy

```
Prädikatswein (highest)
  Kabinett → Spätlese → Auslese → Beerenauslese → Eiswein → TBA
Qualitätswein (QbA)
Landwein
Wein (basic)
```

**Remember:** The Prädikat indicates grape ripeness at harvest, not necessarily sweetness in the glass.  
`Trocken` = dry. `Halbtrocken` / `Feinherb` = off-dry. No modifier + QbA/Prädikat = likely off-dry.

### German Label Anatomy

```
WEINGUT [PRODUCER]          ← Wine estate
[VILLAGE] [VINEYARD]        ← e.g., Erdener Treppchen
[GRAPE] [PRÄDIKAT]          ← e.g., Riesling Spätlese
[REGION]                    ← e.g., Mosel
[VINTAGE]
[ALCOHOL]% vol — (low = likely off-dry)
```

### VDP Classification (Germany's Top Estates Association)

| VDP Tier | Equivalent To |
|---------|--------------|
| Gutswein | Estate wine |
| Ortswein (Village) | Village-level |
| Erste Lage (1er Lage) | Premier Cru equivalent |
| Grosses Gewächs (GG) | Grand Cru dry wine |

### Key German Terms

| German | Meaning |
|--------|---------|
| Trocken | Dry |
| Halbtrocken / Feinherb | Off-dry |
| Süß | Sweet |
| Weingut | Wine estate |
| Winzer | Winemaker |
| Erzeugerabfüllung | Estate-bottled |
| GG (Grosses Gewächs) | Dry Grand Cru |
| Sekt | German sparkling wine |
| Perlwein | Lightly sparkling |
| Einzellage | Single vineyard |
| Grosslage | Group of vineyards (less specific) |

## Austria

### Quality Hierarchy (DAC system)

Austria's DAC (*Districtus Austriae Controllatus*) parallels the French AOC. Key DACs include: Wachau (not technically DAC but its own Vinea Wachau classification), Kamptal DAC, Kremstal DAC, Grüner Veltliner DAC, Burgenland.

### Wachau Vinea Wachau Classification

| Tier | Max Alcohol | Style |
|------|-------------|-------|
| Steinfeder | 11% | Light, delicate |
| Federspiel | 11–12.5% | Classic dry |
| Smaragd | 12.5%+ | Rich, full-bodied dry |

### Key Austrian Terms

| German/Austrian | Meaning |
|----------------|---------|
| Weingut | Wine estate |
| Winzer | Winemaker |
| Trocken | Dry |
| Strohwein / Schilfwein | Straw wine (dried grapes) |
| Trockenbeerenauslese | Dried botrytis-affected grapes (TBA) |
| Ruster Ausbruch | Burgenland sweet wine (between BA and TBA) |

## New World Label Logic

### Key Principle: Labels Show Brand + Grape (+ Region)

```
BRAND NAME          ← Most prominent (e.g., Penfolds, Cloudy Bay)
WINE NAME / TIER    ← e.g., "Bin 389", "Reserve"
GRAPE VARIETY       ← e.g., Cabernet Sauvignon, Sauvignon Blanc
REGION              ← From broad (South Australia) to specific (Barossa Valley)
VINTAGE
VOLUME + ALCOHOL
```

### "Reserve" Caveat

In most New World countries, "Reserve" has **no legal definition** and can mean anything. In the US, it means nothing legally. Judge by producer reputation, not this term.

### US AVA System

AVA = American Viticultural Area.  
- 85% of grapes must come from the stated AVA  
- Napa Valley → sub-AVAs: Oakville, Rutherford, Stags Leap District, Howell Mountain, etc.  
- Smaller AVA = typically more specific and prestigious

### Australia GI System

Geographical Indication (GI).  
- Broad: South Australia, Western Australia, Victoria  
- More specific: Barossa Valley, McLaren Vale, Margaret River, Coonawarra  
- Coonawarra = famous for its unique red terra rossa over limestone soils → premium Cabernet

## What to Check on Every Bottle (3-second scan)

1. **Country** → sets the label logic
2. **Appellation / Region** → gives you style expectations
3. **Grape variety** (stated or known from appellation) → flavor profile
4. **Vintage** → age and quality reference
5. **Producer** → reputation (once you start recognizing names)
6. **Alcohol %** → approximate body/ripeness
7. **Any quality tier / aging indication** → structure, food compatibility

# Tasting Vocabulary

100+ wine descriptors organized by category. Use this as a reference when tasting and when writing tasting notes.

See [Module 6 — The Art of Tasting](../modules/06-tasting.md) for the full tasting framework.

---

## Color Descriptors

### White Wines
| Term | Description | Typical Wine |
|------|-------------|-------------|
| Water-white / colorless | Extremely pale | Very young, unoaked white |
| Pale straw | Very light yellow | Young Pinot Grigio, Muscadet |
| Straw / light gold | Standard young white | Most commercial whites |
| Deep gold | Richer, older, or oaked | Aged Chardonnay, botrytis wines |
| Amber / orange | Skin-contact (orange wine) or very old | Orange wine, aged Riesling |
| Brown | Very old or oxidized | Old Madeira, aged Sherry |

### Red Wines
| Term | Description | Typical Wine |
|------|-------------|-------------|
| Purple / violet | Very young | Young Malbec, Merlot, Syrah |
| Ruby | Young to mid-age red | Most current-release reds |
| Garnet | Some development, medium age | Burgundy, aged Chianti |
| Brick / tile | Older, developed | Aged Barolo, Rioja Gran Reserva |
| Tawny | Very old or oxidized | Tawny Port, very old Grenache |

**Intensity:** pale / medium / deep / very deep / opaque (dense)

## Aroma Descriptors

### Primary — Fruit

**Fresh Fruit (typically young, conventional wines)**
- Apple (green apple — cool climate whites; ripe apple — warmer)
- Pear (Pinot Grigio, lighter whites)
- Peach, apricot (Viognier, Riesling, ripe Chardonnay)
- Lemon, lime, grapefruit, orange (aromatic whites, sparkling)
- Pineapple, mango, passion fruit (New World warm climate whites)
- Cherry (red — Barbera, Dolcetto; black — Merlot, Malbec)
- Raspberry, strawberry (Pinot Noir, Grenache, Gamay)
- Blackcurrant / cassis (Cabernet Sauvignon — classic descriptor)
- Blackberry, blueberry (Syrah, Malbec, Zinfandel)
- Plum (Merlot, Malbec, Tempranillo)

**Dried Fruit**
- Raisin, prune, fig (late-harvest, warm climate, or dried-grape wines like Amarone)
- Dried cherry, dried cranberry (aged Nebbiolo, aged Pinot Noir)
- Dried apricot, quince paste (aged whites, sweet wines, orange wine)

**Citrus Peel**
- Orange peel (Grenache, some Viognier)
- Lemon zest (Sauvignon Blanc, Chablis)
- Bergamot (some cool-climate whites)

### Primary — Floral
- Rose, rose petal (Nebbiolo — classic; also Gewürztraminer, Pinot Noir)
- Violet (Syrah, Malbec, Nebbiolo — classic)
- Jasmine (Viognier, some Riesling)
- Orange blossom (Viognier, Muscat, Malvasia)
- Elderflower (Sauvignon Blanc, some Riesling)
- Lavender (Grenache, Provence rosé)

### Primary — Herbal/Vegetal
- Cut grass (Sauvignon Blanc)
- Green pepper / bell pepper (Cabernet Franc, underripe Cabernet Sauvignon)
- Tomato leaf / tomato stem (Sauvignon Blanc, Sangiovese)
- Asparagus (Sauvignon Blanc)
- Eucalyptus / mint (Australian Cabernet, Malbec)
- Bay leaf, thyme, rosemary (southern French reds, Sangiovese)
- Fennel (Friulano, Vermentino)
- Chamomile (Friulano, delicate whites)

### Primary — Mineral
- Chalk / wet stone / flint (Chablis, Sancerre, Riesling, Vitovska)
- Saline / sea air (Albariño, Manzanilla Sherry, Vitovska, coastal whites)
- Iodine (very coastal whites, Manzanilla)
- Graphite / pencil shaving (mature Cabernet, oak-aged reds)

---

### Secondary — Fermentation-Derived

- Bread / brioche (lees contact in sparkling wine, Champagne)
- Biscuit (aged Champagne, Crémant)
- Butter / cream (malolactic fermentation in white wines)
- Yogurt / lactic (MLF in whites)
- Yeast / sourdough (natural-yeast fermented wines)
- Banana / bubblegum (carbonic maceration — Beaujolais)

---

### Tertiary — Aging (Oak + Bottle)

**Oak-Derived**
- Vanilla (American oak especially)
- Coconut (American oak)
- Toast, smoke, char (barrel toasting)
- Cedar / cigar box (French oak + bottle age, Cabernet)
- Spice: clove, cinnamon, nutmeg (various oak influences)
- Chocolate / cocoa (oak + dark fruit in full reds)

**Bottle Age — White**
- Petrol / kerosene (aged Riesling — TDN compound, considered positive)
- Honey, beeswax (aged whites, botrytis)
- Dried flowers (aged whites)
- Marmalade, candied citrus (aged Riesling, Gewürztraminer)
- Toast (aged Champagne)

**Bottle Age — Red**
- Leather, saddle (aged Cabernet, Barolo)
- Tobacco, cigar (aged Bordeaux, Barolo)
- Earth, forest floor, mushroom (aged Pinot Noir, Burgundy)
- Game (aged Pinot Noir, aged Syrah)
- Coffee (aged full reds with oak)
- Truffle (aged Nebbiolo, aged Burgundy)
- Dried herbs, dried flowers (aged Grenache, aged Italian reds)
- Soy, miso (very aged wines with umami development)

**Orange Wine Specific**
- Walnut, hazelnut (skin-contact oxidative aging)
- Dried apricot, quince (skin-contact whites)
- Chamomile tea (aged orange wines)
- Dried herbs (aged orange wines)
- Ginger (some orange wines, Vitovska)

## Palate Descriptors

### Sweetness
| Term | Residual Sugar |
|------|---------------|
| Bone dry | < 1 g/L |
| Dry | 1–4 g/L |
| Off-dry / hint of sweetness | 4–12 g/L |
| Medium-dry | 12–30 g/L |
| Medium-sweet | 30–60 g/L |
| Sweet | 60–120 g/L |
| Very sweet / luscious | > 120 g/L |

### Acidity
| Term | Meaning |
|------|---------|
| Flat / flabby | Low acidity — wine feels lifeless |
| Soft | Low-medium acidity |
| Fresh | Good, pleasant acidity |
| Crisp | Clear, refreshing acidity |
| Vibrant / lively | High, energetic acidity |
| Mouth-watering | Very high acidity — salivation |
| Sharp | Very high, possibly unbalanced acidity |
| Tart | Very high with a pithy quality |
| Bracing | Extremely high acidity |

### Tannin (Reds Only)
| Term | Meaning |
|------|---------|
| Grippy | Strong tannin sensation |
| Drying | Tannins dehydrate the palate |
| Firm | Substantial tannin, present but structured |
| Smooth | Low, polished tannin |
| Silky | Barely perceptible fine-grained tannin |
| Velvety | Even smoother — seamless |
| Coarse / harsh | Rough tannin — often young or poor wine |
| Green / astringent | Tannin from underripe grapes — unpleasant |
| Powdery | Fine but dry tannin texture |
| Ripe tannins | Smooth, fruit-integrated tannin from fully ripe grapes |

### Alcohol
| Term | Meaning |
|------|---------|
| Low | Under 11% — delicate, light-feeling |
| Medium | 11–13% — balanced, doesn't dominate |
| High | 14–15% — warming, rich |
| Hot | Disproportionate alcohol burn — imbalance |

### Body
| Term | Weight/Mouthfeel |
|------|----------------|
| Light-bodied | Closest to water in weight |
| Medium-bodied | Closest to whole milk |
| Full-bodied | Heaviest, most viscous |
| Lean | Light body with structure |
| Fat | Full body, low acidity, rich texture |
| Round | Medium body, soft acidity and tannin |

### Texture
| Term | Meaning |
|------|---------|
| Creamy | Smooth, rounded, MLF-influenced |
| Watery | Thin, dilute |
| Oily | Rich, viscous (often positive in full whites) |
| Grippy | Tannic and/or high acidity giving substance |
| Mineral | Chalky, stony texture (hard to define precisely) |
| Saline | Salt sensation on the palate — coastal wines, Vitovska |

## Finish / Aftertaste

| Term | Meaning |
|------|---------|
| Short | Flavors disappear in under 5 seconds |
| Medium | 5–15 seconds |
| Long | 15–30 seconds — quality signal |
| Very long / persistent | 30+ seconds — great wine |
| Clean | No unpleasant aftertaste |
| Bitter | Slight bitter note — can be positive (almonds in Friulano, Soave) or negative |
| Astringent finish | Tannin drying in the aftertaste |
| Warming finish | Alcohol lingering — can be positive or "hot" |
| Saline finish | Mineral, briny aftertaste — positive |

## Overall Character Descriptors

| Term | Meaning |
|------|---------|
| Austere | Lean, minimal fruit, classic European style |
| Backward | Not yet showing potential; needs aging |
| Balanced | All elements in harmony |
| Brooding | Dark, deep, concentrated, slightly closed |
| Classic | Typifies its region and grape |
| Clean | No faults; clear aromas and flavors |
| Closed | Not showing aromas; needs aeration or aging |
| Complex | Multiple layers, evolving |
| Concentrated | Very intense flavor |
| Earthy | Soil, mushroom, truffle, organic matter |
| Elegant | Refined, not heavy, harmonious |
| Evolved | Showing age, development |
| Forward | Fruit immediately obvious; ready to drink |
| Fresh | High acidity, lively, vibrant |
| Generous | Abundant fruit, warm, open |
| Harmonious | Balanced; everything working together |
| Intellectual | Subtle, complex, rewards contemplation |
| Meaty | Savory, dense, sometimes literally meat-like |
| Mineral | Stony, chalky, flinty character |
| Modern | Fruit-forward, oak-influenced, internationally styled |
| Opulent | Very rich, generous, almost excessive |
| Precise | Focused, defined, clear |
| Primary | Showing fresh fruit, fermentation character; young |
| Rustic | Rough edges, traditional, charming imperfection |
| Serious | Has depth and structure suggesting aging potential |
| Structured | High tannin and/or acidity providing backbone |
| Supple | Soft, flexible, approachable |
| Tertiary | Showing age, development, secondary character |
| Tight | Concentrated, closed, needs time |
| Traditional | Aged in large oak, minimal extraction, classic style |
| Typicity | Expresses the character typical of its grape and region |
| Unoaked / Inox | Made in stainless steel; pure fruit, no oak flavor |

## Wine Faults

| Fault | Descriptor | Cause |
|-------|-----------|-------|
| Corked (TCA) | Wet cardboard, musty basement | Contaminated cork |
| Oxidized | Flat, brown, Sherry-like (unintenionally) | Oxygen exposure |
| Volatile Acidity (VA) | Vinegar, nail polish remover | Acetic acid / ethyl acetate |
| Reduction | Struck match, rubber, garlic | Sulfur compounds |
| Brett (Brettanomyces) | Barnyard, leather, band-aid, horse | Wild yeast contamination |
| Heat damage | Cooked, jammy, flat, dried fruit | Overheating during transport |
| Re-fermentation | Unexpected bubbles | Residual sugar + yeast |
| Mousy | Mouse cage smell (hard to detect cold) | Bacterial spoilage |

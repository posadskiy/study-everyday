# Daily Nutrition

> Current goal: lose weight slowly from **81 kg** while staying healthy for running. Simple rule: **breakfast + lunch every day; add post-run recovery only on run days. No routine food after 19:00.**

## Current Targets

| Day | Calories | Protein | Structure |
|-----|----------|---------|-----------|
| Rest day | **1900–2100 kcal** | **160–175 g** | Breakfast + lunch |
| Weekday run day | **2300–2500 kcal** | **160–175 g** | Same breakfast + lunch + post-run recovery |
| Saturday long run | **3000–3600 kcal** | **160–180 g** | Light breakfast + run fuel + recovery meal + lunch |

Target weight loss: **0.3–0.5 kg/week**. Faster than that risks poor recovery and injury.

## Calories Per Meal

Use these as practical targets. They do not need to be exact every day.

| Day | Breakfast | Lunch | Post-run / recovery | During run | Optional before 19:00 | Total |
|-----|-----------|-------|---------------------|------------|-----------------------|-------|
| Rest day | **800–900 kcal** | **1100–1200 kcal** | — | — | — | **1900–2100 kcal** |
| Weekday run day | **800–900 kcal** | **1000–1100 kcal** | **450–500 kcal** | — | — | **2250–2500 kcal** |
| Saturday long run | **300–500 kcal** | **1300–1700 kcal** | **600–800 kcal** | **0–400 kcal** | **0–300 kcal** | **3000–3600 kcal** |

### Protein Per Meal

| Day | Breakfast | Lunch | Post-run / recovery |
|-----|-----------|-------|---------------------|
| Rest day | **60–75 g** | **90–100 g** | — |
| Weekday run day | **50–70 g** | **70–90 g** | **30–40 g** |
| Saturday long run | **10–25 g** | **80–100 g** | **40 g** |

On Saturday, breakfast is intentionally smaller. The missing calories are moved to the recovery meal and lunch, where digestion is no longer a problem.

## Normal Days

Use this for rest days and weekday run days.

| Time | Rest day | Weekday run day |
|------|----------|-----------------|
| Morning | Breakfast | Breakfast |
| Midday | Lunch | Lunch |
| After run | — | **30–40 g protein + 50–70 g carbs** |
| After 19:00 | No planned food | Only post-run recovery if the run finished late |

Breakfast and lunch should be the same basic size every day. The run-day difference comes from the recovery food after the run.

### Breakfast

Target: **800–900 kcal** on normal days, protein + carbs.

Examples:
- Greek yogurt + oats + banana + honey
- Eggs + bread + fruit
- Cottage cheese + oats/bread + fruit
- Whey + oats + banana if you need something quick

### Lunch

Target: **1000–1200 kcal**, protein + carbs. Use the lower end on weekday run days if you need easier digestion before the afternoon run.

Examples:
- Chicken/fish/beef + rice/potatoes/pasta + vegetables
- Eggs + bread/potatoes + vegetables
- Cottage cheese/Greek yogurt added if protein is low

On run days, keep lunch lower fat and lower fiber so it digests before the afternoon run.

## After Weekday Runs

Within 30 minutes:

| Nutrient | Amount |
|----------|--------|
| Protein | **30–40 g** |
| Carbs | **50–70 g** |

Simple options:
- Whey + banana + bread/jam
- Greek yogurt + banana + honey
- Cottage cheese + rice cakes + jam
- Eggs on toast

If the run finishes after 18:00, still take this. It is recovery food, not a snack.

---

## Saturday Long Run Day

A normal big breakfast before a 9:00 run is too heavy. Eat light before, then make up calories after.

| Time | What |
|------|------|
| 7:00–7:30 | **Light breakfast**: 300–500 kcal, mostly easy carbs |
| During run | Fuel if run is >75–90 min |
| 11:00–11:30 | **Recovery meal**: 40 g protein + 80–120 g carbs |
| ~14:00 | Lunch: main meal |
| Before 19:00 | Optional extra protein + carbs only if the run was long and calories are still low |

Light breakfast options:
- Banana + rice cakes + honey
- Toast + honey/jam
- Small oats + banana
- Small yogurt + banana

Avoid before the run: eggs with cheese, fried food, nuts/oil-heavy meals, high-fiber bread, very large breakfast.

---

## Strength Before Breakfast

No extra food is required just because strength happens before breakfast.

| Situation | What to do |
|-----------|------------|
| You feel fine fasted | Train, then eat normal breakfast |
| You feel weak/dizzy | Banana or small yogurt before strength; count it as part of breakfast |
| Strength + run day | Breakfast after strength, run recovery after afternoon run |

Optional tendon support: **15 g collagen + 50 mg vitamin C** 30–60 min before strength.

## Supplements

| Supplement | Dose | When |
|------------|------|------|
| Creatine monohydrate | **5 g daily** | Run days: with post-run recovery. Rest days: with breakfast or lunch. |
| Vitamin D | Test first if possible | Take with a fatty meal if low. Important for bone adaptation. |

Creatine may increase scale weight by **1–2 kg** in the first 2–3 weeks. This is water inside muscle, not fat.

| | |

## Phases

| Phase | Months | Focus |
|---|---|---|
| [Phase 1 — Structure & Brevity](phase-1-structure-brevity.md) | 1–3 | Stop rambling. Structure thoughts before speaking or writing. |
| [Phase 2 — Voice & Confidence](phase-2-voice-confidence.md) | 4–6 | Speak under pressure. Build comfort in EN and RU. |
| [Phase 3 — Listening & Hard Conversations](phase-3-listening-hard-conversations.md) | 7–9 | Stop preparing replies while others talk. Give feedback that lands. |
| [Phase 4 — Integration & Output](phase-4-integration-output.md) | 10–12 | Produce real artifacts in both languages. Cement by teaching. |

## Key Research Principles (2025–2026)

- **Blended learning beats pure self-study** — online + live/in-person yields 43% higher behavioral transfer (2025 Corporate Learning Benchmark)
- **Micro-learning + spaced repetition** — short daily drills beat occasional long sessions; 58% higher completion (ATD Research, 2024)
- **Peer practice > instruction alone** — peer coaching shows 52% better retention (ICF, 2024)
- **COMPASS model** (Hamzah et al., 2025): soft skills only stick when **Capability** (knowing how) + **Opportunity** (real practice) + **Motivation** (wanting to) are all present

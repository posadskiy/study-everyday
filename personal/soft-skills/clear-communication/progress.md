# Progress Tracker

## How to Use

- **Weekly**: add one line after each practice session
- **Monthly**: complete the COMPASS self-check and record yourself answering the prompt
- **Month 12**: compare your latest recording to the Month 1 recording

---

## Monthly Recording Prompt

> "Tell me about a recent challenge at work and how you handled it."

Record yourself answering this in English, then in Russian.
Save the file with the month number. Compare M12 to M1.
